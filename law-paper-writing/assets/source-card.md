# 来源卡模板

为需要持续追溯的资料复制一张卡片。按材料类型填写有关字段。工作稿的来源编号关联到这里，必要时可在简表中记录同样的信息。

## 身份与版本

| 字段 | 内容 |
| --- | --- |
| 来源编号 | 待填写，如 S001 |
| 材料类型 | 规范、学术文献、文书、官方案例摘要、报告或其他 |
| 标题 | 待填写 |
| 作者或发布机关 | 待核 |
| 文号、案号或官方案例编号 | 待核或不适用 |
| 刊物、卷期、出版社、起讫页或文章编号 | 待核或不适用 |
| 版本及 DOI、ISBN 或其他稳定编号 | 例：网络首发、正式发表、修订文本 |
| 制定、裁判、公布或发表日期 | 按类型分别记录 |
| 网页发布日期或更新日期 | 待核或不适用 |
| 生效日、修订日、失效日及适用时段 | 分别记录，关联确认依据 |
| 法律性质、法域、位阶、地域及适用对象 | 待核或不适用 |
| 原发布链接或数据库标识 | 待填写 |
| 实际阅读的链接或文件、版本和访问日 | 仅有摘要、转引等情形按实填写 |
| 关联来源编号及关系 | 如 S002 的译本、S003 更正的旧版、S005 的二审文书 |

## 原文定位与支持范围

| 对应判断编号及稿件位置 | 印刷页、条款或段落 | PDF 文件页或网页小节 | 最小必要原文或忠实摘要 | 支持程度、范围和限制 | 仍需补充的推理或材料 |
| --- | --- | --- | --- | --- | --- |

## 核验记录

| 核验项目 | 状态与范围 | 核验日期、实际渠道和依据 | 缺口及影响 |
| --- | --- | --- | --- |
| 取得范围 | 全文、片段、摘要、二手转引、仅书目或未取得 | 待填写 | 待填写 |
| 身份与版本核验 | 待填写 | 待填写 | 待填写 |
| 引文及定位核验 | 逐段记录，例：指定段落已核、页码待核 | 待填写 | 待填写 |
| 当前条款状态 | 待填写或不适用 | 核验截止日、依据文件及条款 | 待填写 |
| 讨论时点的条款状态与个案适用 | 待填写或不适用 | 事实时段、裁判或审查时点、过渡及适用依据 | 待填写 |
| 出版更新 | 更正、撤稿、重新发表或不适用 | 出版者通知或登记信息 | 影响的判断 |

案例另记案件标识、文书标识、相关主体、事实、争点、程序阶段、机关理由和处理结果，并定位到对应原文。报告和数据另记统计期间、单位、样本、口径与换算。引用不同版本中的不同段落可分别建卡并记录版本关系。
