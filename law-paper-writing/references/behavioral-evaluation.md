# 写作 Skill 的行为验收

作者要求验收 Skill 时，先确定被测版本、任务范围和评审者。答题只接收模拟用户指令与相应材料。将作者原稿、范文、历史稿的身份按输入保留。盲评时把两份原始回答换成随机编号，再由评审者对照预期要点和评分条目逐项判定，记录失分位置或被遗漏的材料。

对同一批任务，分别报告无 Skill 和有 Skill 的表现。比较版本时固定模型、材料、工具权限与评分标准，只更换 Skill 版本。编造来源或引注、把未取得的原文写成已核实、未经授权改变作者核心立场、删去必要限定导致过度断言，均按题内标准判为否决。

语言验收成对盲评充分材料和有限材料的起草题。每份答案独立记录主张清晰度、含糊回避和证据匹配。候选版的清晰度须提高，含糊回避须减少，证据匹配至少持平。任一题出现反向变化即判回归。验收报告列明覆盖范围、人工评分和对应的原始回答。

源码仓库的 `law-paper-writing/evaluations/behavioral/README.md` 提供题库和操作步骤，`law-paper-writing/evaluations/run_behavioral.py` 检查目录并汇总人工判分。题库作为维护资料保存在源码仓库，安装包包含本说明。
