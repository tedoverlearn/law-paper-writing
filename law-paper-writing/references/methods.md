# 研究方法与推论范围

根据研究问题选择方法。混合研究为每个关键命题写清使用何种方法、材料提供何种依据、下一步还需要什么理由。先查证实际涉及的法域和时点，再采用该法域的法源与先例规则。

| 问题 | 首先确定 | 最少交付 |
| --- | --- | --- |
| 规则如何解释或适用 | 法域、判断时点、法源与争点 | 有依据的解释及其适用条件、竞争解释 |
| 实践中出现了什么 | 分析单位、材料覆盖、程序阶段 | 可回溯的个案观察或样本描述 |
| 怎样理解文本或历史概念 | 语词、体裁、版本与解释对象 | 逐处细读、语境与竞争读法。见[文本与历史解释](text-and-history.md) |
| 怎样论证一个概念或价值判断 | 概念所指、评价标准和连接前提 | 论证重建、反例与可选修订。见[理论与规范论证](theory-and-normative-argument.md) |
| 行动者怎样理解或经历一种实践 | 材料如何取得，研究者角色与分析取向 | 可定位的观察、分析所得判断及范围。见[质性与混合方法](qualitative-and-mixed-methods.md) |
| 什么因素解释结果 | 因素、结果、时间顺序及比较条件 | 有限的机制解释、关联或有识别依据的因果判断 |
| 规则或实践是否正当 | 评价标准、受影响主体、经核实的事实前提 | 有适用条件的评价及异议处理 |
| 制度应如何改变 | 现行框架、目标、可行方案与实施条件 | 明确拟改变的规则、权限或程序及其理由 |

## 规范与教义学分析

确定法域、时间、对象和规范问题。核对相关法源的性质、版本、适用范围与相互关系。

1. 顺着授权、构成要件、例外、法律效果查找相关规范，按法域核对其拘束力或参考作用。处理跨期事实时确定规范适用所依据的事件日期与过渡条款。
2. 定位争议发生在哪个术语、要件或规则关系。列出原文允许讨论的解释方案及其实际差异。
3. 用与问题相关的文义、体系、立法沿革、目的或其他解释依据检验各方案。援引法典编排作体系解释时，说明编排如何与条文用语、构成要件或相邻规定相互印证。保护法益、行为对象与法律效果各按所需依据论证。对存在争议的目的说明来源。主张某规范优先适用时，先核对适用范围是否重叠，再说明位阶、特别关系或时间关系依据。
4. 给出解释在典型情形、边界情形和例外中的效果。仍有并存解释时，交代何种条件决定选择，保留材料与法理上的不确定点。

援用裁判时，按[裁判理由与推论范围](#裁判理由与推论范围)说明裁判所解决的问题、支撑结果的理由以及其在本法域的作用。讨论类推时交代规则是否存在需要填补的漏洞、共同的规范理由、影响结论的重要差异及该法域或领域的类推限制。

实践做法可以提示解释问题。由实践走向规范结论时补充合法性与正当性理由。提出修法方案时，分别说明现行规则的解释结果和建议方案的预期作用。

## 理论与价值论证

明示评价标准的来源、适用范围和内部张力。利益衡量列明受影响主体、损益发生的条件、举证材料、可能替代方案及分配后果。适用比例或平等审查时，先说明所用审查结构及其法域和制度依据。用同一标准检查支持和反对结论的事例。

讨论刑罚时，分别说明报应所依据的责任与相称性、威慑所依赖的行为反应、保安措施所依据的风险判断，以及权利和程序保障施加的约束。合用多项理由时，写清哪一项支持采取措施、哪一项限定对象或强度。理由冲突时交代选择所依赖的规范依据和代价。

预测制度后果时标明所需经验前提。经验材料不足时保留条件式判断，并交代该前提改变后对结论的影响。

## 案例研究与有限比较

先说明选案目的，是展示一种可能、检验反例、重建裁判理由还是描述公开样本。确定分析单位是事件、案件、文书、请求、争点还是主体。按该单位计数并保留关联。同案一审与二审可以作为两个程序观察点，比较独立案件时按案件归并。同一材料的转载与原载互相关联，事实尚不足以确认同案时注明疑点。

| 比较项目 | 记录内容 | 对比较的影响 |
| --- | --- | --- |
| 法律框架 | 法域、规范版本、具体争点和适用标准 | 规则变化可能解释结果差异 |
| 关键事实 | 与待比较要件有关的行为、损害、角色、抗辩或其他情节 | 判断相近程度取决于这些事实与争点的关系 |
| 程序条件 | 阶段、诉讼请求或指控、证明标准、证据状态 | 程序性处理与实体判断各按其适用条件理解 |
| 机构与时期 | 作出决定的机关、层级、地区和时间 | 可能存在制度及办案环境差异 |
| 结果与理由 | 精确到具体主体、裁判或处理项目，标明理由在原文的位置 | 相同结果可以出自不同理由 |
| 来源完整度 | 完整文书、官方摘要、报道或二手转述，关键事实的记录状态 | 缺失事实会限制规则与原因判断 |

按待比较命题选择维度，将每案在相关维度的记录和原文定位并列。每组给出可比到哪一步、哪些差异可能改变结论、哪些前提尚缺以及补什么材料才可进一步比较。程序或规则差异阻碍结果比较时，仍可对照符合条件的理由或程序节点。

记录未知的具体原因，例如发布材料未披露、原文未取得、文本含义存疑。只有来源明确记载某事实不存在时，才按明确否定处理。

### 裁判理由与推论范围

先按[案例与文书](sources-and-citations.md#案例与文书)查明文本身份、取得范围及案例使用状态，再对照论文引用的命题检查以下步骤。

- **定位理由。** 对照具体请求、争点和主文，判断法院实际采用了什么理由。说明各项理由如何共同支撑结果，哪些各自足以支撑结果，哪些段落只是假设讨论或背景说明。删去一项仍有其他理由支撑结果时，继续查法院是否也实际采用了该项。使用“裁判理由”和“旁论”作分析时，另按实际法域说明其先例作用。
- **核实版本和可比性。** 比较法院实际使用的规范版本、依事实时点与过渡规则应适用的版本，以及论文所讨论时点的规范。按争点比对关键事实对应的要件、抗辩、请求或程序条件。程序性结案所及的争点和实体裁判所及的争点需分别核实。同一案由或相同结果只提供比对线索。
- **校准推论。** 已核实的个案可以说明某种结果在给定条件下确曾发生，也可以检验与之相抵的全称命题。用个案指出制度风险时，说明哪些程序或规则条件使风险有可能发生。估计风险的发生概率须有相应样本、分母及覆盖依据。仅有目的性选例时，频率表述限于已选案例。解释现行法时补上文本及体系等规范理由。主张应当采纳某种做法或据以修法时，具体说明为何值得普遍采纳，按问题论证权限、受影响利益、制度代价或替代方案。

交付时定位原稿及所见文本，写明是哪一步越界、目前可成立到哪里，以及还欠哪项材料或理由。只核查时报告判断与缺口。作者需要修订时，再按授权给出改稿或示范表述。多处疑点可用表格对照，单一问题直接说明。

## 实证研究

以目标总体、可观察材料、检索命中、最终样本为顺序说明取得过程。检查每一步的流失或过滤，例如纠纷进入诉讼、形成可研究文书、公开与收录、检索命中、筛选去重及关键字段可编码。记录能核实的数量、时间、机构、筛选条件和排除理由，未知数量保留未知。

采用结构化编码或量化测度时，把概念转成可观察指标，记录单位、判断标准、来源字段、边界例子与缺失处理。先用少量典型和边界材料试编码。需要一致判码时记录分歧、复核办法和最终规则。自动抽取的关键字段回查原文，报告实际复核范围。抽取裁判理由时，区分文书披露的理由、研究者的推断与待证明的实际动机。访谈主题分析等方法按各自分析传统选择质量检查。

| 拟写出的经验判断 | 需要检查 |
| --- | --- |
| 个案或样本内描述 | 分析单位、有效分母、缺失数量、重复观测和统计口径 |
| 目标总体的频率或分布 | 样本如何覆盖总体、纳入机会是否受结果影响、哪些群体或期间缺失 |
| 关联 | 变量可比性、共同变化因素、样本选择、替代口径下是否仍成立 |
| 因果影响 | 比较或识别设计、时间顺序、可辩护的识别假设及替代解释 |

计算比例前逐项核对分子与分母是否属于同一单位、时空范围和筛选口径。结果未知时报告未知数和已知数。样本全量收录也要检查公开材料与目标总体的差距。检索零命中只说明给定查询和可访问范围内的结果，进一步检查同义词、检索字段、载体与可访问的时间范围。

有比较或模型结果时，说明所估计的关系与范围。控制变量要看时间顺序、法律或事实逻辑及其与待解释机制的关系。示例性个案支持机制讨论时，交代可观察的过程证据和仍可能成立的其他解释。数据条件允许时，检查改动纳入规则或未知项处理对结论的影响，并保留可复核的资料、编码与计算记录。

访谈或观察研究记录招募、观察范围、研究者角色、记载和分析办法，说明受访者陈述能支持的对象与范围。涉及隐私、知情同意或研究伦理审查时按项目实际适用要求核对，输出遵守已知引用和披露约束。

## 比较法与法律史

比较法先确定共同问题、比较单位与法域选择理由。按具体问题采用功能、概念、制度结构、历史或实践语境等需要的维度。分别重建各法域内部的规范来源、原文术语、适用时点、主体、程序与法律效果，再比较。缺少实践资料时将判断限定在成文规则或已经核对的裁判。提出借鉴时写明本地权限配置、执行能力、程序保障与配套规则等必要条件。

使用外国实证研究时，写明研究对象、制度和执行背景、观察范围及结论所及。用它解释中国情境时，说明哪些机制和条件可以比较，并核对会改变结果的本地差异。缺少本地依据时，可用外国材料提出待检验的机制或风险，发生率与政策效果限于原研究情境。有关中国法的解释结论还须以本地法源和解释理由论证。

法律史记录史料产生时间、形成与使用者、体裁、保存和版本关系、编纂删节及术语语境。按原始记录、整理本和后世叙述逐项注明。对照同一时期可取得的规范、记录及其他来源，检验“规范要求”“记录呈现”“实践推断”各自的根据。现代概念用于分析时说明用途及对当时语义的处理。史料可见度随档案保存与史料选编变化，比较不同时段的记录时查明变化发生在哪一环。

研究一个事件如何获得长期制度意义时，使用[制度变迁方法](institutional-history.md)。先确定在哪个阶段提出解释，再选择当时决策、后续实践或回顾性叙述的资料核验该解释。

## 结论表达

对每个关键结论说明材料直接呈现的内容、作者增加的推理以及仍待证明的前提。把时空范围、适用条件、样本覆盖和未决异议写到相应判断附近。在同一篇论文中从经验观察转到解释或制度建议时，写明经验判断在该论证中承担的前提，并补足独立的规范依据或评价理由。

材料只足以排除某一罪名时，直接写明该罪名及未满足的要件。对行为整体作不可罚判断时，再核对与该行为有关的其他罪名和处罚依据。有实质依据的竞争解释尚待辨别，或关键制度条件尚未查明时，指出受影响的结论，并写出证据仍足以支持的判断。

证据缺口影响核心命题时，提出可供作者选择的较窄主张，并展示它保留了原论证的哪些部分。按授权决定是否改入正文。
