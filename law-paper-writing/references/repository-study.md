## 仓库结构

仓库按构思、检索、写作、投稿、返修、模板和演讲组织论文写作资料。这个阶段划分为本 Skill 的全过程流程提供了组织思路。各环节的输入、交付、完成条件、法学专门方法和测试用例由本项目编写。[仓库说明](https://github.com/secdr/research-method/blob/master/README.md)

## 法学适配

| 原资料的工作场景 | 本 Skill 的适配处理 |
| --- | --- |
| 科研贡献与研究依据 | 依据命题性质检验，分别使用规范解释、价值理由、经验材料和反例 |
| 相关研究阅读 | 按法学争议组织观点，保留限定、原文页码与方法差异 |
| 论文正文与引文 | 增加法源性质、版本、讨论时点、文书身份与具体主张的对应 |
| 写作技巧和模板 | 作为可选择的方法资源，章节安排服从论文问题及交付要求 |
| 投稿和回应 | 核对目标机构的正式要求，记录实际修改及作者授权 |

来源材料的科研范式和英文表达建议在法学任务中按需要转化。法源核验、案例可比性、作者决定机制、来源卡和验收方法属于本项目的具体设计。
