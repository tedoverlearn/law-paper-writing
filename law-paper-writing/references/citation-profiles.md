# 引注体例选择与转换

## 确认本次采用的体例

先确定稿件用途、适用对象和交付版本。按作者明确指定的体例整理工作稿。面向学校、期刊或会议提交时，核对该次提交适用的通知、正式指南或编辑要求，并附来源和日期。若作者指定的版次与提交要求有冲突，说明冲突和影响，先完成两种体例共通的核验工作。

机构文件明确指定标准版次时，记录该版次及文件适用范围。机构文件只写“最新版”时，查发布者所示的状态和生效日期。只列标准编号而版次不明时，结合正式附件与示例判断。仍有歧义时，可先给出暂定写法和待确认项。

未指定目标时，先统一工作稿中的资料字段和定位。作者要求预选体例时，结合论文语言、法域和交付场景说明选择，并在稿件说明中注明暂用版本。

## 摘取与转换

从正式要求摘出当前稿件用到的规则。保留规则出处、章节、适用条件和发布日期或访问日期。操作表可用以下字段。

| 本次需处理的项目 | 适用规则及原文位置 | 稿件样例位置 | 已核状态或待确认项 |
| --- | --- | --- | --- |
| 脚注、文末文献及各自收录范围 |  |  |  |
| 各材料类型的必要信息、顺序与定位 |  |  |  |
| 首次引用、重复引用、跨注或简称 |  |  |  |
| 外文、译本、网络文献和转引 |  |  |  |

转格式前保留工作稿的来源编号、版本、原文位置和原有可编辑文件。先选稿件中实际存在的材料类型试排，再批量应用。编号、近接重复引注和交叉引用在当前稿件顺序确定后复查。

涉及 Zotero 等生成的引用时，保留带可更新字段的原稿。若作者明确需要不带引用字段的交付稿，另存副本后再执行。手工校正可写入条目元数据或插件支持的字段。编辑正文后用刷新功能重生成，并对照目标要求抽查复杂条目及重复引注。[Zotero Word 插件文档](https://www.zotero.org/support/word_processor_plugin_usage)

转换结果应可反查原来来源。若某种材料的样式缺失或渲染不完整，标出该条、所据规则和可人工复核的候选写法。将学位稿改为投稿稿时分别保存完成的体例选择及稿件版本。
