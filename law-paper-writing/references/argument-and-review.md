# 论证与质量审查

## 关键判断的记录

先定位作者的研究问题、结论和当前允许的修改范围。对直接影响结论的判断，按下表记录必要信息。局部任务只检查所涉判断及其直接依赖。

| 字段 | 要回答的问题 |
| --- | --- |
| 主张编号及位置 | 这一判断在哪里，依赖哪些前文判断，哪些结论又依赖它 |
| 命题性质 | 是文本阐释、历史判断、规范解释、经验推论、价值评价还是制度建议 |
| 前提和依据 | 依赖什么规范、事实、研究或评价标准，来源编号和原文位置是什么，核验实际到哪一步 |
| 连接理由 | 为什么这些依据支持该主张，哪个中间步骤需要单独论证 |
| 反对意见 | 持相反立场者最有力的论证及其来源是什么 |
| 回应与边界 | 涉及哪些主体、要件、时点、法域或样本，哪些情形仍构成例外 |
| 作者决定 | 已确认、研究假设或待选择，以及本轮允许的修改范围 |

写出可追溯的最短推导。涉及不同性质的命题时，将推导所需的附加依据一并列出。检查每处引用是直接支持、支持某个前提、提供反证，还是仅提供背景。学者同意某判断可作为学术讨论材料，其论证仍需检验。

用同一命题的弱式与强式检查作者的论证。例如，“在取得的文书中可见某理由”依赖可核对的个案。“该理由经常决定结果”还涉及总体覆盖、决定性理由及替代解释。用词与证据能够支持的命题对应。

## 反例与竞争解释

围绕争点寻找足以改变关键判断的异议。已有文献或裁判出处时定位原文。根据材料推演可能的审稿异议时，说明这是本轮推演及依赖的条件。先准确重建对方的主张和最强理由，再说明它如何作用于本文。

遇到反例先核对其真实性、适用条件和主张范围，再定位受影响的推理步骤。

| 核对后的情况 | 判断与处理 |
| --- | --- |
| 反例落在主张适用范围内，且否定全称或必要条件命题 | 指出被否定的明确命题。审查例外有无独立依据，按实际理由提出收窄或撤回 |
| 反例落在主张适用范围内，挑战的是“通常”“较可能”等命题 | 记录例外及其与样本范围的关系，继续核对频率和辅助条件 |
| 个案存在影响结论的范围差异 | 标明差异及为何与争点有关，并给出两案仍可比较的方面 |
| 相同结果也可由其他机制解释 | 寻找能够区别竞争解释的事实，根据材料给出有限判断 |
| 异议挑战评价标准、价值排序或制度可行性 | 核对异议所指前提，用同一标准比较方案，说明需要接受的取舍 |
| 反例所用的事实、规则或来源身份仍有疑问 | 给出条件式判断，列明有待核实的原文和事实 |

在修订建议中指出哪个主张、前提或连接理由受影响，并追查依赖它的摘要、引言、正文、结语和引注。能回应时写明回应所依赖的材料。回应仍需补证时，给出带条件的保留方案和与现有材料相称的修订方案。作者授权范围内完成修改，涉及尚未授权的立场改变时保留为方案。

经验命题要说明何种观察会要求改变判断。解释论和价值命题要说明哪些规范理由、解释冲突、反例或后果会削弱它。适用条件随反例而变时，检查收窄后的条件能否一致解释未用于形成该条件的其他材料。

正文以“唯一”“始终”等措辞概括时，检查脚注和附录是否记录了意涵不同的材料。反材料的含义有争议时，说明它挑战的是哪一判断、依据实际取得的版本，以及还要核对的原文。单一事实同时符合几种解释时，列出能够区分它们的观察。

## 分层审查

| 审查项 | 合格表现 | 发现问题后的处理 |
| --- | --- | --- |
| 问题与贡献 | 问题可回答，贡献与检索范围及正文相称 | 收窄问题或修改贡献表述 |
| 方法适配 | 方法能够承担拟作的解释或推论 | 调整方法、补充材料或收窄结论 |
| 材料与版本 | 版本、归属、语境和支持位置清楚。涉及法源时另核效力和程序 | 核对原文并定位受影响判断 |
| 推理完整 | 关键前提、连接理由和依赖关系可检验 | 修补相应推理并复查受影响内容 |
| 反对意见 | 最强异议得到公平重建与实际回应 | 加入反论证并检查其对结论的影响 |
| 引注支持 | 关键转述和引文可回溯到对应位置并保留原文限定 | 区分来源取得与命题支持问题，按实际材料修注、补证或改写 |
| 结构与语言 | 术语稳定、章节各有任务、段落关系清楚 | 按作者风格改进表达 |
| 交付要求 | 摘要、匿名、格式与实际要求对应 | 修正指定文件并复查 |

按实际影响给出处理顺序。每项列出稿件定位、当前判断、具体缺口、可能影响和可执行修改。指出现有材料能支持的表述。用户只要求评审或局部编辑时，可在建议中描述受影响的其他段落。

## 中文学术表达

先确定本轮是语言润色、结构调整，还是实质改稿。只润色时，编辑表达并保留原判断的归属、程度与边界。参考范文时借鉴行文习惯，范文中的论据、经历和立场仍归其原作者。

- 段落从读者需要知道的主体、争点或条件写起，再给出新的理由。删去重复铺垫、无依据的拔高和只起装饰作用的并列。有具体作用的程序术语、过渡和背景保留。
- 对照原稿检查主体、对象、时间、数量、否定、条件、例外、因果和归因。尤其核对“可以”与“应当”、“超过”与“以上”、当事人主张与法院判断，以及关联与因果。把相同含义的冗余限定减至足够表达的程度。
- 引号内原文、数据、案号、来源编号和法条位置按原材料及用户授权处理。拆句、合并或移段后复核脚注是否还跟随原来支撑的命题。无法确定词语指涉时保留原判断并在稿外指出缺口。
- 有作者样稿时，以其中稳定的术语、句长和叙述顺序辅助编辑。无样稿时延续已有文体。英文摘要、译文和正文若表达同一判断，比对各自的主体、模态词和结论范围。
- 样稿只有一篇时，取用本轮能指出位置和用途的写法，例如用一个影响决策的细节引出问题。作者确认适合反复采用的写法可记为偏好。修辞中的拟言、反问和类比按原文作用处理，涉及当事人或机构的直接引语另核原文。

### 证据边界与防御性句子

一句话如果只用来预防假想质疑，没有提供新的事实、理由或适用条件，直接删掉。重复说明同一边界时，保留最清楚的一处。

涉及技术、程序或证据边界时，写明现有材料能支持的判断。更宽的判断与研究问题有关时，再交代所需材料或条件。例如，“这八份公开文书可用于分析所列案件的裁判理由。估计同类案件的支持比例，需要统一取样口径，并取得涵盖支持和驳回结果的案件记录。”

改写后对照原句，确认判断强度和适用范围。原文只提出某些条件与结果有关时，沿用关联表述。描述当事人事前能否预见结果时，写明需要知道当事人在当时掌握的信息。对事后材料的解释按其实际作用表述。

保留具有法律或论证意义的否定，例如规范明文排除的条件、作者对争议命题的反对、来源明确记载的驳回或调查范围内实际未观察到的结果。直接引文依原文保留。

只要最终文字时直接交付改稿。仅发现实质问题且作者授权不足时，保留原意并说明疑点所在，供另行核验或修订。

## 交付前硬门禁

按实际稿件版本逐项记录核验结果。每条须标为通过、待处理或不适用，并写明依据及位置。不适用须说明本件为何无此内容，例如当前局部交付只有一段，未收到摘要。

| 门禁 | 通过条件与记录 |
| --- | --- |
| 关键命题可追溯 | 必须登记稿件位置、主张、来源编号及所用原文位置。页码、条款、段落或档案叶码须能复查。记录规范版本及个案适用时点。作者的推论与原文记载分别注明，并记录连接理由。 |
| 引注取得范围真实 | 未取得原文的引注必须显式标为仅见摘要、转引、书目或实际取得的其他范围。须写出所见材料的来源和位置。只见书目时不得写出该文的实质判断。 |
| 各部分结论强度相称 | 必须逐项将摘要、引言、结语的同一命题对应到正文，核对主体、模态、因果强度、频率、范围及例外。缺少必要部分或发现拔高、稀释时须记在对应命题下。词表命中用于定位复读，由审查人核对实际命题。 |
| 待核项集中 | 影响交付的待核项必须汇入一份清单，逐项给出稿件位置、影响的主张、所需材料或核验动作。改稿后重新检查是否已解决。 |
| 作者授权可回查 | 改动核心立场必须能够回查作者的明确授权。记录主张、授权原话或定位、日期、获准改动及稿件版本。超出授权的改法只作候选。 |

任一硬门禁未通过，不得标为定稿、可投稿或已完成核验。可以先交付工作稿和待核清单。局部任务核验获授权且可见的内容，登记影响后续稿件的事项。材料齐备后，须在拟交付版本上重核。

## 稿件扫描

对 UTF-8 Markdown 或纯文本的拟交付稿运行下列脚本。Word 稿先导出保留标题、正文、注号、参考文献的文本，并用 [Word 脚注检查](../scripts/audit_docx_footnotes.py)核对 DOCX 的注释关系，再核对 Word 中实际显示的注号。

```sh
python -X utf8 law-paper-writing/scripts/check_manuscript.py manuscript.md
python -X utf8 law-paper-writing/scripts/check_manuscript.py manuscript.md --check-hedging
```

扫描会列出占位、参考文献重复、注号和摘要与正文的结论强度词差异。返回码 0 表示扫描范围内通过，1 表示有复读候选，2 表示有阻断项或输入无法读取。参照[主张与必要限定](claims-and-qualifications.md)复核语言提示。引注取得范围、作者授权和跨章节的同一命题仍须按门禁表逐项核验。

在导出的文本中保留“摘要”“正文或章节标题”“脚注”“参考文献”等节名。可用 Markdown 标题、独占一行的节名或“摘要：”引出摘要。参考文献一条占一行，扫描核对归一化后相同的著录。注号支持从 1 连续编号的 `[^1]` 和 `〔注1〕`。脚注定义可用 `[^1]:`，或在脚注节内用 `〔注1〕`、`注1：`。逐章重编号的稿件按章扫描。结论强度词的候选比较依据是措辞相同的命题片段，改述、跨句推理与不同词表维度由审查人回到稿件核对。

## 定稿审查

对照引言逐项查正文是否完成承诺，对照结语检查是否新增判断。检查标题的概念与正文定义、摘要结论与正文范围、图表口径与文本解释、各处交叉引用是否一致。

完成实质修改后沿论证依赖关系复查受影响的段落与引注。逐项检查必要条件和例外是否同步更新，反方表述与回应是否仍对应。交付时说明已改项、仍待核验的结论和作者待选方案。审阅只覆盖部分原稿时标明具体范围。

## 方法参考

- 郑州市中级人民法院的论文写作指引要求法院学术论文将观点、理由和证据对应，并在修订时检查论证链条。本模块采用其论证与复核方法，面向各类法学论文按题目和实际规范使用。[《郑州法院学术论文写作指引》，第六、第八部分](https://zzfy.hncourt.gov.cn/public/detail.php?id=30200)
- 哈佛学院写作中心建议寻找合理读者可能提出的异议，并视异议影响调整原论证。本模块据此将异议定位到主张、前提及推导步骤。[Counterargument](https://writingcenter.fas.harvard.edu/counterargument)
