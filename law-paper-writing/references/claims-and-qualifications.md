# 主张与必要限定

读者应能从论证中找到作者的判断、根据和推导。争点已经清楚时，可以直接回答。解释取决于一个词或一条记录时，可以先让读者看到那处材料。负责铺陈、解读引文或承接上文的段落，完成它在全文中的任务即可。作者保留的判断交由作者决定。

## 逐句决定限定的去留

试删后重读判断。删去“现存三页”会把“现存三页均有签名”读成全册的结论，这一限定应保留。法域、施行时点、样本分母、原文取得范围、适用条件和真实的反例，也可能改变读者能从一句话推出什么。删去预防假想质疑或邻句已经说清的缓冲。跨章复述时，按新位置的上下文补回读者仍需知道的条件。

## 六种改法

| 遇到的写法 | 怎样改 |
| --- | --- |
| “可能”“在一定程度上”等措辞遮住了判断 | 查明措辞对应的不确定性。有证据依据的可能性按原强度表达，能写清的条件直接写出。 |
| 并非简单的……、不能一概而论、不是……而是……、并不意味着…… | 查后半句是否给出实质新信息。只有立场姿态的整句删除，有具体区分就把区分写清。 |
| 段首排列一串假想异议 | 找出材料中真正影响结论的异议，放在它所检验的前提或推理旁。需要借异议引出问题时，可以从异议写起。 |
| 本文无意、不敢妄断、浅见、刍议、抛砖引玉、笔者才疏学浅 | 删除作者正文中的自谦、免责措辞。引述他人时保持引文和题名原貌。 |
| 连续交代“有待进一步研究”“尚需更多材料” | 写出现有材料能成立的最强判断。更宽的问题确实关系到本段时，再具体说明哪项材料可以区分两种答案。 |
| 抽象名词和无主语遮住了判断 | 恢复材料中的主体、动作与对象。例如“法院驳回了请求”。只有材料记载了理由，才归纳法院据以裁判的考虑。 |

修订后对照原材料，核对改动涉及的判断是否仍在证据支持的范围内。删去必要限定造成过度断言，在行为验收中一票否决。缓冲词的数量只帮助找到复读的位置。
