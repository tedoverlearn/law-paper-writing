# 主张与必要限定

每个论证段至少写出一句作者自己的判断。写清谁做了什么、哪条规则怎样处理哪类事实，或哪份材料支持哪种解释。用接下来的句子给证据和推理。材料充分就直接断言。作者保留的判断交由作者决定。

## 逐句决定限定的去留

1. 找出限定对应的具体事实。法域、施行时点、样本分母、原文取得范围、适用条件和材料中实际出现的反例，都可以构成 A 类必要限定。只为预防假想质疑而写的 B 类修辞直接删掉。
2. 试删后重读判断。如果读者会把“现存三页均有签名”读成“全册每页均有签名”，保留“现存三页”。如果删改只让句子更短，去掉缓冲。
3. 检查邻句。同一边界在离判断最近的位置写一次，后文接着论证。跨章摘用让指代或适用范围发生变化时，补回理解该段必需的条件。

## 六种改法

| 遇到的写法 | 怎样改 |
| --- | --- |
| 在一定程度上、某种意义上、或许、似乎、一定程度上、可能、不难发现、值得注意的是、需要指出的是、应当承认、不可否认 | 先写判断。单个判断句至多保留一个有事实依据的缓冲词，能写清条件时直接写条件。 |
| 并非简单的……、不能一概而论、不是……而是……、并不意味着…… | 查后半句是否给出实质新信息。只有立场姿态的整句删除，有具体区分就把区分写清。 |
| 段首排列一串假想异议 | 先写主张，再回应材料中威胁它最强的异议，指出该异议影响哪一步推理。 |
| 本文无意、不敢妄断、浅见、刍议、抛砖引玉、笔者才疏学浅 | 删除作者正文中的自谦、免责措辞。引述他人时保持引文和题名原貌。 |
| 连续交代“有待进一步研究”“尚需更多材料” | 写出现有材料能成立的最强判断。更宽的问题确实关系到本段时，再具体说明哪项材料可以区分两种答案。 |
| 抽象名词和无主语遮住了判断 | 恢复材料中的主体、动作与对象。例如“法院驳回了请求”。只有材料记载了理由，才归纳法院据以裁判的考虑。 |

修订后对照原材料，再看每段主张是否仍在证据支持的范围内。删去必要限定造成过度断言，在行为验收中一票否决。缓冲词的数量只帮助找到复读的位置。
